# お客様アカウント情報の修正

登録したお客様のアカウント情報を確認し、修正する方法をご案内します。

***

### アカウント情報の修正

{% stepper %}
{% step %}
ログイン後、ホームページ右上のプロフィール（アカウント）アイコンをタップします。

<figure><img src="../.gitbook/assets/member-info-1.png" alt="" width="355"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
\[My情報管理]画面へアクセスし、情報を修正します。

<figure><img src="../.gitbook/assets/member-info-2.png" alt="" width="270"><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

### My情報管理の画面

<figure><img src="../.gitbook/assets/member-info-screen.png" alt="" width="288"><figcaption></figcaption></figure>

![](../.gitbook/assets/icon-square-1.svg) 基本情報の管理

* お名前、携帯電話番号、メールアドレスを確認し\[変更]をタップして修正します。

![](../.gitbook/assets/icon-square-2.svg) パスワード

* \[変更]をタップし、パスワードを変更します。

![](../.gitbook/assets/icon-square-3.svg) ログアウト

* 現在のアカウントからログアウトします。

![](../.gitbook/assets/icon-square-4.svg) 退会

* アカウントを削除（退会）します。

{% hint style="danger" %}
退会すると、アカウントおよび保存された情報がすべて削除され、復元できません。退会前に必要な情報を予めご確認ください。
{% endhint %}
