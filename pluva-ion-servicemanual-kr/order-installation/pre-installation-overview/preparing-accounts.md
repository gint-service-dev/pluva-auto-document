# 고객 계정 준비

플루바 아이온을 사용하려면 먼저 통합회원가입 홈페이지에서 계정을 만들어야 합니다. 아래 순서대로 회원가입합니다.<br>

{% hint style="info" %}
[플루바 아이온 홈페이지 바로가기](https://gint.pluva.kr/)
{% endhint %}

{% stepper %}
{% step %}
[플루바 아이온 회원가입 홈페이지](https://gint.pluva.kr/)에 접속해 \[회원가입하기]를 누릅니다.

<figure><img src="../../.gitbook/assets/preparing-accounts-1.png" alt="" width="270"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
이름, 휴대폰 번호, 비밀번호를 입력한 후 \[휴대폰 번호 인증하기]를 누릅니다.

<figure><img src="../../.gitbook/assets/preparing-accounts-2.png" alt="" width="341"><figcaption></figcaption></figure>

{% hint style="info" %}
이메일은 선택 항목으로, 입력하지 않아도 회원가입을 진행할 수 있습니다.
{% endhint %}
{% endstep %}

{% step %}
휴대폰 번호로 전송된 인증번호 6자리를 입력하고 \[인증완료]를 누릅니다.

<figure><img src="../../.gitbook/assets/preparing-accounts-3.png" alt="" width="333"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
휴대폰 번호 인증이 완료되면 약관 동의를 체크하고 \[가입완료]를 누릅니다.

<figure><img src="../../.gitbook/assets/preparing-accounts-4.png" alt="" width="330"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
회원가입이 완료됩니다.

<figure><img src="../../.gitbook/assets/preparing-accounts-5.png" alt="" width="270"><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
