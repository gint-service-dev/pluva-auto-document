# 소프트웨어 업데이트(OTA)

#### 소프트웨어 업데이트(OTA) **이란?**

최신 성능으로 안정적인 사용 환경을 제공하기 위해 기기가 자동으로 최신 버전을 확인하고 업데이트합니다.

{% hint style="info" %}
최신 업데이트가 필요한 경우에만 소프트웨어 설정 화면이 표시됩니다.
{% endhint %}

{% hint style="warning" %}
소프트웨어 업데이트(OTA) 진행 시 약 **300MB \~ 500MB**의 데이터가 사용됩니다. 고객의 데이터 요금제를 사전에 확인하고, 데이터가 충분하지 않은 경우 Wi-Fi 또는 테더링 환경을 준비합니다.
{% endhint %}

***

{% stepper %}
{% step %}
\[업데이트] 버튼을 누릅니다.

<figure><img src="../../.gitbook/assets/image (366).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
와이파이 환경에서 소프트웨어 업데이트를 진행할 것을 권장합니다.
{% endhint %}

{% hint style="info" %}
네트워크가 셀룰러로 설정되어 있는 경우 \[네트워크 변경]을 통해 변경할 수 있습니다.
{% endhint %}
{% endstep %}

{% step %}
업데이트가 진행됩니다.

<figure><img src="../../.gitbook/assets/image (367).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
업데이트 중에는 자동 재시작 됩니다. 잠시 기다려 주세요.

<figure><img src="../../.gitbook/assets/image (368).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
\[다음 단계로] 버튼을 누르면 소프트웨어 업데이트가 완료됩니다.

<figure><img src="../../.gitbook/assets/image (369).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

{% hint style="info" %}
**업데이트 실패 시 확인 사항**

네트워크 또는 시스템 오류가 발생하거나 업데이트 중 전원이 꺼지면 실패할 수 있습니다. 네트워크와 전원 상태를 확인한 후 다시 시도해 주세요.
{% endhint %}
