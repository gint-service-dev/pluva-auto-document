# 제품 개통 확인

QR 스캔을 통해 제품이 개통 되었는지 확인합니다.

{% hint style="info" %}
사전에 제품 개통을 완료하여야 합니다. 자세한 내용은 [제품 개통 페이지](https://servicemanual.pluva.io/ion/korea/kr/order-installation/product-registration)를 참고해주세요.
{% endhint %}

    <div align="left"><figure><img src="../../.gitbook/assets/image (364).png" alt="" width="375"><figcaption></figcaption></figure></div>
