# 현장 기록 작성

제품 설치와 퀵셋업을 마친 뒤, 어드민에 설치·교육 내용과 현장에서 발생한 문제, 피드백을 기록합니다. 남긴 기록은 이후 점검과 고객 지원에 활용할 수 있습니다.

***

{% stepper %}
{% step %}
어드민에서 \[설치 티켓 목록]을 열고, 기록을 남길 고객의 티켓을 누릅니다.

<div align="left"><figure><img src="../.gitbook/assets/image (450).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
\[현장 기록]에서 작성할 항목을 선택하고 \[작성]을 누릅니다.

{% hint style="info" %}
설치, 교육, 이슈 발생, 고객 피드백, 담당자 피드백 중 내용에 맞는 항목을 선택하여 작성할 수 있습니다.

![](<../.gitbook/assets/image (457).png>)
{% endhint %}

<div align="left"><figure><img src="../.gitbook/assets/image (455).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
기록할 내용을 입력하고, 필요한 사진이나 동영상을 첨부합니다.

{% hint style="info" %}
\[사진/영상 (최대 8개)]을 눌러 파일을 첨부합니다. 사진과 동영상은 합쳐서 최대 8개까지 첨부할 수 있습니다.
{% endhint %}

<div align="left"><figure><img src="../.gitbook/assets/image (452).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
작성한 내용과 첨부 파일을 확인한 뒤 \[추가]를 누릅니다.

{% hint style="info" %}
첨부 파일을 더 넣으려면 \[+]를, 잘못 첨부한 파일을 빼려면 해당 파일의 \[×]를 누릅니다.
{% endhint %}

<div align="left"><figure><img src="../.gitbook/assets/image (454).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
목록에 기록이 추가됩니다.

<div align="left"><figure><img src="../.gitbook/assets/image (456).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
