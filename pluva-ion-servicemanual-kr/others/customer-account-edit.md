# 고객 계정 정보 수정

가입한 고객 계정의 정보를 확인하고 수정하는 방법을 안내합니다.

***

### 계정 정보 수정

{% stepper %}
{% step %}
로그인 후 홈페이지 우측 상단의 프로필(계정) 아이콘을 누릅니다.

<figure><img src="../.gitbook/assets/member-info-1.png" alt="" width="355"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
\[내 정보 관리] 화면으로 들어가고 원하는 정보를 수정합니다.

<figure><img src="../.gitbook/assets/member-info-2.png" alt="" width="270"><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

### 내 정보 관리 화면

<figure><img src="../.gitbook/assets/member-info-screen.png" alt="" width="288"><figcaption></figcaption></figure>

![](../.gitbook/assets/icon-square-1.svg) **기본 정보 관리**

* 이름, 휴대폰 번호, 이메일을 확인하고 \[변경]으로 수정합니다.

![](../.gitbook/assets/icon-square-2.svg) 비밀번호

* \[변경]으로 비밀번호를 수정합니다.

![](../.gitbook/assets/icon-square-3.svg) 로그아웃

* 현재 계정에서 로그아웃합니다.

![](../.gitbook/assets/icon-square-4.svg) 회원탈퇴

* 계정을 탈퇴합니다.

{% hint style="danger" %}
회원탈퇴 시 계정과 저장된 정보가 모두 삭제되며, 삭제된 정보는 다시 복구할 수 없습니다. 탈퇴 전에 필요한 정보를 미리 확인하세요.
{% endhint %}
