# 시스템 진단 (업데이트)

위치 신호, 통신, 조향 장치와 태블릿의 현재 상태를 확인합니다. 문제가 있는 항목에는 원인과 조치 방법이 함께 표시됩니다.

***

### 진입 방법 <a href="#undefined" id="undefined"></a>

{% stepper %}
{% step %}
주행 화면 하단의 메뉴 버튼을 누릅니다.

<figure><img src="../.gitbook/assets/image (181).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
왼쪽 메뉴에서 \[시스템 진단]을 선택합니다.

<figure><img src="../.gitbook/assets/image (182).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

### 화면 설명

<figure><img src="../.gitbook/assets/image (185).png" alt=""><figcaption></figcaption></figure>

<img src="../.gitbook/assets/image (186).png" alt="" data-size="line"> **위치**

* 위성 신호(GNSS), 위치 보정 신호와 GNSS 수신기 상태를 확인합니다.

<img src="../.gitbook/assets/image (187).png" alt="" data-size="line"> **통신**

* 네트워크 연결 상태를 확인합니다.

<img src="../.gitbook/assets/image (188).png" alt="" data-size="line"> **제어**

* 조향 장치의 연결 및 오류 상태를 확인합니다.

<img src="../.gitbook/assets/image (189).png" alt="" data-size="line"> **온도**

* 태블릿 온도와 과열 여부를 확인합니다.

### 경고·위험 상태 확인하기

\[경고] 또는 \[위험] 상태인 항목은 시스템 진단 화면 상단의 ‘확인 필요’ 영역에 표시됩니다. 아래 순서로 원인과 조치 방법을 확인합니다.

{% stepper %}
{% step %}
주행 화면 상단에 경고 아이콘이 나타나면 아이콘을 누릅니다.

<figure><img src="../.gitbook/assets/image (285).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
‘확인 필요’에 표시된 원인과 조치 방법을 확인하고, 화면의 안내에 따라 조치합니다.

<figure><img src="../.gitbook/assets/image (287).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**조치 후 확인**

* 상태가 \[정상]으로 바뀌었는지 확인합니다.
* 문제가 계속되면 대리점에 문의합니다.
{% endhint %}
{% endstep %}
{% endstepper %}
