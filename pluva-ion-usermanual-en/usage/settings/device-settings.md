# 기기 설정 (업데이트)

태블릿의 화면 밝기와 음량, 카메라 표시, 지도 및 블루투스 연결을 설정합니다.

***

### 진입 방법

{% stepper %}
{% step %}

<figure><img src="../../.gitbook/assets/screen-settings-1.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
왼쪽 메뉴에서 \[기기 설정]을 누르면 기기 설정 화면으로 들어갑니다.

<figure><img src="../../.gitbook/assets/image (213).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

### 화면 설정

화면 밝기와 음량, 카메라 표시를 설정합니다.

<figure><img src="../../.gitbook/assets/image (214).png" alt=""><figcaption></figcaption></figure>

![](../../.gitbook/assets/icon-square-1.svg) **화면 밝기**

* 슬라이더를 드래그하여 화면 밝기를 조절합니다.

![](../../.gitbook/assets/icon-square-2.svg) **음량**

* 슬라이더를 드래그하여 음량을 조절합니다.
  * **예시 듣기**: 설정한 음량을 미리 들어봅니다.
  * **음량 초기화**: 음량을 기본값으로 되돌립니다.

{% hint style="info" %}
블루투스 기기가 연결되면, 태블릿 대신 연결된 블루투스 기기의 음량을 조절합니다.

<img src="../../.gitbook/assets/image (8).png" alt="" data-size="original">
{% endhint %}

![](../../.gitbook/assets/icon-square-3.svg) **카메라**

* 주행 화면에 카메라 영상 표시 여부를 설정합니다.
  * **전체 카메라**: 카메라를 한 번에 켜거나 끕니다.
  * **유턴 시 자동 켜짐**: 유턴할 때 카메라가 자동으로 켜집니다.
  * **카메라 좌우 반전**: 카메라 영상의 좌우를 바꿔 표시합니다.
  * **카메라 상하 반전**: 카메라 영상의 상하를 바꿔 표시합니다.

***

### 지도 설정

주행시 표시되는 지도 소스를 선택할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (215).png" alt=""><figcaption></figcaption></figure>

* **일반 지도**: 한국 공공 지도 서비스의 위성 사진 데이터를 사용합니다.
* **구글 지도**: 구글에서 제공하는 위성 사진 데이터를 사용합니다.
* **2D 지도**: 위성 사진이 아닌 평면 지도를 사용합니다.

***

### 입력 설정

원터치 스위치의 버튼 작동음을 설정합니다.

<figure><img src="../../.gitbook/assets/image (212).png" alt=""><figcaption></figcaption></figure>

* 원터치 스위치 음량: 버튼 작동음을 켜거나 끕니다.
* 버튼 작동음 안내: 작동음의 종류와 의미를 확인합니다.

{% hint style="info" %}
- \[원터치 스위치 음량]을 켠 뒤, \[버튼 작동음 안내] 옆의 ⓘ를 누릅니다.
- \[예시 듣기]를 눌러 각 작동음을 미리 들어볼 수 있습니다.
- \[원터치 스위치 음량]이 꺼져 있으면 \[예시 듣기]가 표시되지 않습니다.

![](<../../.gitbook/assets/image (220).png>)
{% endhint %}

{% hint style="info" %}
**작동음별 의미**

\[OK] 버튼으로 선택 내용을 확인하면 확인음이 재생됩니다. LED가 꺼진 버튼은 현재 사용할 수 없으며, 누르면 사용 불가음이 재생됩니다.
{% endhint %}

***

### 기기 정보

기기의 기본 정보를 확인하고 저장된 작업 데이터를 초기화할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (216).png" alt=""><figcaption></figcaption></figure>

![](../../.gitbook/assets/icon-square-1.svg) **기기 일련번호**

* 기기의 일련번호가 표시됩니다.

![](../../.gitbook/assets/icon-square-2.svg) **데이터 초기화**

* 등록된 연결정보를 모두 해제하고 초기 설정 상태로 되돌립니다.
* 데이터 초기화 시 초기 화면으로 이동하여 퀵셋업을 처음부터 다시합니다.

{% hint style="warning" %}
주의: 데이터 초기화 시 모든 데이터가 영구 삭제되며 복구할 수 없습니다.
{% endhint %}

***

### 블루투스 연결 <a href="#bluetooth-connect" id="bluetooth-connect"></a>

주변 블루투스 기기를 태블릿에 연결하고, 연결 상태와 음량을 관리합니다.

<figure><img src="../../.gitbook/assets/image (217).png" alt=""><figcaption></figcaption></figure>

<img src="../../.gitbook/assets/image (11).png" alt="" data-size="line"> **블루투스 연결**

* 블루투스 연결을 켜거나 끕니다.

<img src="../../.gitbook/assets/image (10).png" alt="" data-size="line"> **등록된 기기**

* 등록한 기기와 연결 상태를 확인합니다. \[연결] 또는 \[연결 해제]를 눌러 연결을 관리합니다.
* ⓘ를 누르면 기기 정보를 확인하거나 \[기기 지우기]를 선택할 수 있습니다.

<img src="../../.gitbook/assets/image (12).png" alt="" data-size="line"> **블루투스 음량**

* 슬라이더로 음량을 조절합니다. \[예시 듣기]를 눌러 소리를 확인할 수 있습니다.

<img src="../../.gitbook/assets/image (16).png" alt="" data-size="line"> **근처 기기**

* 주변에서 검색된 기기를 확인합니다. \[기기 검색]을 누르면 이름으로 기기를 찾을 수 있습니다.

{% hint style="info" %}
**새 기기를 연결하는 방법**

블루투스를 켠 뒤, \[근처 기기] 목록에서 연결할 기기의 \[연결]을 누르세요. 연결이 완료되면 \[연결됨]으로 표시됩니다.
{% endhint %}
