# アカウントの作成及び管理

pluva ionをご利用いただくには、まず統合会員登録サイトでアカウントを作成する必要があります。以下の手順に従って会員登録を行ってください。<br>

{% hint style="info" %}
[pluva ionのホームページへ](https://gint.pluva.jp/)
{% endhint %}

{% stepper %}
{% step %}
[pluva ionの会員登録サイト](https://gint.pluva.jp/)の会員登録サイトへアクセスし、\[会員登録]をタップします。

<figure><img src="../../.gitbook/assets/preparing-accounts-1.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
お名前、携帯電話番号、パスワードを入力してから\[携帯電話番号から認証する]をタップします。

<figure><img src="../../.gitbook/assets/preparing-accounts-2.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
メールアドレスの入力は任意です。入力しなくても会員登録を進めることができます。
{% endhint %}
{% endstep %}

{% step %}
携帯電話番号に送信された6桁の認証コードを入力し、\[認証完了]をタップします。

<figure><img src="../../.gitbook/assets/preparing-accounts-3.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
携帯電話番号の認証が完了したら、利用規約に同意の上\[登録完了]をタップします。

<figure><img src="../../.gitbook/assets/preparing-accounts-4.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
会員登録が完了されます。

<figure><img src="../../.gitbook/assets/preparing-accounts-5.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

### アカウント情報の修正

{% stepper %}
{% step %}
ログイン後、ホームページ右上のプロフィール（アカウント）アイコンをタップします。

<figure><img src="../../.gitbook/assets/member-info-1.png" alt="" width="355"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
\[My情報管理]画面にアクセスし、情報を修正します。

<figure><img src="../../.gitbook/assets/member-info-2.png" alt="" width="270"><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

### My情報管理画面

<figure><img src="../../.gitbook/assets/member-info-screen.png" alt="" width="288"><figcaption></figcaption></figure>

![](<../../.gitbook/assets/icon-square-1 (1).svg>) **基本情報の管理**

* お名前、携帯電話番号、メールアドレスを確認し\[変更]をタップして修正します。

![](<../../.gitbook/assets/icon-square-2 (1).svg>) パスワード

* \[変更]をタップし、パスワードを修正します。

![](<../../.gitbook/assets/icon-square-3 (1).svg>) ログアウト

* 現在のアカウントからログアウトします。

![](<../../.gitbook/assets/icon-square-4 (1).svg>) 退会

* アカウントを削除（退会）します。

{% hint style="danger" %}
退会すると、アカウントおよび保存された情報がすべて削除され、削除された情報は復元できません。退会前に必要な情報を予めご確認ください。
{% endhint %}
