# 圃場の登録

一度圃場を登録すれば、各作業で同一の基準を適用できるため、作業準備時間を短縮し、繰り返しの設定を最小限に抑えることができます。また、作業履歴が圃場単位で蓄積・照会されるため、圃場ごとの作業記録を簡単に確認でき、農作業の体系的な管理が可能です。

***

#### 圃場登録機能へアクセス

{% stepper %}
{% step %}
![](../../.gitbook/assets/ic_menu.svg) \[メニュー一覧のアイコン]をクリックします。

<figure><img src="../../.gitbook/assets/field-registration-1.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
My Farmの農場管理の\[圃場]タブをクリックすると圃場の管理へアクセスできます。

<figure><img src="../../.gitbook/assets/field-registration-2.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
![](../../.gitbook/assets/add-button.svg) \[圃場の追加]ボタンをクリックします。

<figure><img src="../../.gitbook/assets/field-registration-3.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
\[確認]をクリックします。

<figure><img src="../../.gitbook/assets/field-registration-4.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

### 地図から登録

{% stepper %}
{% step %}
「地図から登録」オプションを選択し、\[確認]をクリックします。

<figure><img src="../../.gitbook/assets/map-registration-1.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
地図から圃場を選択します。

<figure><img src="../../.gitbook/assets/map-registration-2.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
圃場登録の基本設定は\[地図から選択]になっています。 境界を直接作成するには、\[直接描く]をクリックします。
{% endhint %}
{% endstep %}

{% step %}
境界の生成後、\[進入口の設定]をクリックし、ご希望の場所を選択します。

<figure><img src="../../.gitbook/assets/map-registration-3.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
進入・退出口の位置設定ポップアップから\[同じ場所に設定]を選択します。

<figure><img src="../../.gitbook/assets/map-registration-4.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
\[退出口を別途設定]を選択した場合は、進入/退出口をそれぞれ指定する必要があります。

<img src="../../.gitbook/assets/select-path-entry.png" alt="" data-size="original">
{% endhint %}
{% endstep %}

{% step %}
進入・退出口の設定が完了したら圃場情報を入力し、\[登録]をクリックします。

<figure><img src="../../.gitbook/assets/map-registration-5.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
圃場の登録が完了します。

<figure><img src="../../.gitbook/assets/map-registration-6.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

### 地図から圃場登録の画面のご案内

<figure><img src="../../.gitbook/assets/field-registration-screen-0.png" alt=""><figcaption></figcaption></figure>

![](../../.gitbook/assets/icon-square-1.svg) **住所を検索し圃場を選択**

* アドレス検索で圃場を選択します。

<div align="left"><figure><img src="../../.gitbook/assets/field-registration-screen-1.png" alt="" width="563"><figcaption></figcaption></figure></div>

![](../../.gitbook/assets/icon-square-2.svg) **直接描く**

* 圃場エリアに直接点を打って生成します。

<div align="left"><figure><img src="../../.gitbook/assets/field-registration-screen-2.png" alt="" width="563"><figcaption></figcaption></figure></div>

![](../../.gitbook/assets/icon-square-3.svg) **地図から選択**

* 地図上で圃場を直接クリックして選択します。\[地図から登録]が基本設定になっています。

![](../../.gitbook/assets/icon-square-4.svg) **前へ**

* 前へ戻ります。

![](../../.gitbook/assets/icon-square-5.svg) **次へ**

* 次へ進みます。

![](../../.gitbook/assets/icon-square-6.svg) **終了する**

* 「圃場を追加する」画面から出ます。

![](../../.gitbook/assets/icon-square-7.svg) **現在地へ移動する**

* 現在地に地図を移動させます。

![](../../.gitbook/assets/icon-square-8.svg) **進入/退出口の設定**

* 進入/退出口の位置を設定します。圃場を選択すると、そのボタンが使用できます。進入/退出口は同じ位置に設定するか、別々に設定することができます。なお、修正ボタンから位置変更ができます。

![](../../.gitbook/assets/icon-square-9.svg) **境界の登録完了**

* 境界登録を完了します。進入/退出口を選択するとそのクリックが可能になります。

### 車両から登録

手動運転し、圃場の境界を走行しながらポイントをマッピングする方法です。地図上に表示されない圃場や、境界が分かりづらい場合に有効です。

{% stepper %}
{% step %}
圃場の登録方法を選択する際に、「車両から登録」をタップし\[確認]を押します。

<figure><img src="../../.gitbook/assets/field-add-vehicle-1 (1).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
車両から登録画面にアクセスできます。車両を圃場の各ポイントへ移動させ、マッピングします。

<figure><img src="../../.gitbook/assets/field-add-vehicle-2 (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
設定直後、該当するポイントの修正ボタンが表示されます。位置を修正したい場合は、修正ボタンをタップして再設定します。
{% endhint %}

{% hint style="warning" %}
**車両から圃場登録時のご注意**

* 最大20ポイントまで設定できます。
* ポイントは順番に設定してください。順不同で設定すると境界線が正しく生成されません。
{% endhint %}

{% hint style="info" %}
ご希望の位置でボタンをタップし、進入口・退出口を設定できます。

<img src="../../.gitbook/assets/entry-exit-path-1.png" alt="" data-size="original">
{% endhint %}
{% endstep %}

{% step %}
「境界の生成完了」をタップします。

<figure><img src="../../.gitbook/assets/field-add-vehicle-3 (1).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
境界の登録が完了すると、圃場登録のボタンが有効になります。「**圃場登録」**&#x3092;押して下さい。

<figure><img src="../../.gitbook/assets/field-add-vehicle-4 (1).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
圃場情報の入力画面から、圃場名、農場、作物などを入力します。**「登録」**&#x3092;タップすると圃場の登録が完了します。

<figure><img src="../../.gitbook/assets/field-add-vehicle-5 (1).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

#### 画面のボタンに関するご案内

<figure><img src="../../.gitbook/assets/field-add-vehicle-screen-buttons-1.png" alt=""><figcaption></figcaption></figure>

* 進入口を車両の現在地に設定します。

![](../../.gitbook/assets/icon-square-2.svg) **退出口の修正**

* 退出口を車両の現在地に設定します。

![](../../.gitbook/assets/icon-square-3.svg) **初期化**

* 設定したポイントを初期化します。

![](../../.gitbook/assets/icon-square-4.svg) **圃場の登録**

* 全てのポイントを設定し終わったら、圃場を登録します。

![](../../.gitbook/assets/icon-square-5.svg) **終了する**

* 登録を中断し、前の画面に戻ります。

![](../../.gitbook/assets/icon-square-6.svg) **修正**

* 既に設定したポイントを現在地に変更します。

![](../../.gitbook/assets/icon-square-7.svg) **A / B / C / D / E / F**&#x20;

* 該当するポイントを車両の現在地に設定します。
