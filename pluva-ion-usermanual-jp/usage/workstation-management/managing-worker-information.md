# 作業機情報の管理

作業機の別名、タイプなどの情報を修正し、削除できる機能です。

***

#### 作業機情報の管理機能へのアクセス

{% stepper %}
{% step %}
![](<../../.gitbook/assets/ic_worker (1).svg>) \[作業機]アイコンをタップします。

<figure><img src="../../.gitbook/assets/managing-worker-1.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
ご希望の作業機カードの\[⋮]アイコンをタップします。

<figure><img src="../../.gitbook/assets/managing-worker-2.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
表示されたポップアップから、ご希望の管理機能を選択します。

<figure><img src="../../.gitbook/assets/managing-worker-3.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

#### 作業機情報の修正

{% stepper %}
{% step %}
\[修正]をタップします。

<figure><img src="../../.gitbook/assets/edit-worker-1.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
別名・作業機のタイプ・幅・畝間などを修正し、\[確認]をタップします。

<figure><img src="../../.gitbook/assets/edit-worker-2.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
修正が完了します。

<figure><img src="../../.gitbook/assets/edit-worker-3.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

***

#### 作業機情報の削除

{% stepper %}
{% step %}
\[削除]をタップします。

<figure><img src="../../.gitbook/assets/delete-worker-1.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
確認画面で\[削除]をタップします。

<figure><img src="../../.gitbook/assets/delete-worker-2.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
削除が完了されます。

<figure><img src="../../.gitbook/assets/delete-worker-3.png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
ご注意: 削除した作業機は、復元できません。
{% endhint %}
{% endstep %}
{% endstepper %}
