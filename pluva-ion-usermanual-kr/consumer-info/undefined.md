# 시스템 진단

위치 신호, 통신, 조향 장치와 태블릿의 현재 상태를 확인합니다. 문제가 있는 항목에는 원인과 조치 방법이 함께 표시됩니다.

***

#### 진입 방법 <a href="#undefined" id="undefined"></a>

{% stepper %}
{% step %}
주행 화면 하단의 메뉴 버튼을 누릅니다.

<figure><img src="../.gitbook/assets/image (164).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
왼쪽 메뉴에서 \[시스템 진단]을 선택합니다.

<figure><img src="../.gitbook/assets/image (165).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
주행 화면 상단에 이상 상태를 알리는 아이콘이 나타나면, 아이콘을 눌러 시스템 진단 화면으로 바로 이동할 수 있습니다.

![](<../.gitbook/assets/image (166).png>)
{% endhint %}
{% endstep %}
{% endstepper %}

#### 화면 설명

<figure><img src="../.gitbook/assets/image (168).png" alt=""><figcaption></figcaption></figure>

<img src="../.gitbook/assets/image (169).png" alt="" data-size="line"> **위치**

* 위성 신호(GNSS), 위치 보정 신호와 GNSS 수신기 상태를 확인합니다.

<img src="../.gitbook/assets/image (170).png" alt="" data-size="line"> **통신**

* 네트워크 연결과 차량 통신 상태를 확인합니다.

<img src="../.gitbook/assets/image (171).png" alt="" data-size="line"> **제어**

* 조향 장치의 연결 및 오류 상태를 확인합니다.

<img src="../.gitbook/assets/image (172).png" alt="" data-size="line"> **온도**

* 태블릿 온도와 과열 여부를 확인합니다.

{% hint style="warning" %}
**문제가 있을 때 확인하는 방법**

* 문제가 표시된 항목의 원인과 조치 방법을 확인합니다.
* 화면의 안내에 따라 조치합니다.
* 상태가 \[정상]으로 바뀌었는지 확인합니다. 문제가 계속되면 대리점에 문의합니다.
{% endhint %}
