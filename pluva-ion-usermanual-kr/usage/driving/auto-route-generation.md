# 자동 경로 (플루바 AI)

자동 경로(플루바 AI)

* 사용자의 필드/차량 조건을 바탕으로 최적의 작업 경로를 자동 생성하는 기능입니다.

<div align="left"><figure><img src="../../.gitbook/assets/automatic-path.png" alt="" width="200"><figcaption></figcaption></figure></div>

{% stepper %}
{% step %}
\[필드 선택] 화면에서 작업할 필드를 선택하고 \[불러오기]를 누릅니다.

{% hint style="info" %}
**자동 경로 사용 전 확인**\
자동 경로를 사용하려면 경계가 등록된 필드를 선택해야 합니다. 등록된 필드가 없다면 [필드 등록](https://pluva-auto.gitbook.io/ion/usage/my-farm/field-add)을 먼저 진행해 주세요.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (303).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
\[자동 경로 추천] 버튼을 누릅니다.

<figure><img src="../../.gitbook/assets/image (308).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
경로 생성이 완료될 때까지 기다립니다.

<figure><img src="../../.gitbook/assets/image (311).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
추천 경로를 확인한 뒤 \[추천된 경로로 주행시작]을 누릅니다.

<figure><img src="../../.gitbook/assets/image (310).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
안내된 시작점으로 이동한 뒤 \[자율주행 시작]을 누릅니다.

<figure><img src="../../.gitbook/assets/image (312).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

{% hint style="info" %}
\[경로 수정] 버튼을 눌러 추천 경로를 변경할 수 있습니다.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (313).png" alt=""><figcaption></figcaption></figure>
