# 필드 수정

등록한 필드의 이름, 농장, 농장 소유자 등의 필드 정보 등 정보를 수정할 수 있는 기능입니다.



***

#### **필드 수정 과정** <a href="#editing" id="editing"></a>

{% stepper %}
{% step %}
![](<../../.gitbook/assets/image (31).png>) 전체 메뉴 아이콘을 누릅니다.

<figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
My Farm의 농장관리의 \[필드 탭] 진입이 완료됩니다.

<figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
원하는 필드 항목의 ![](https://usermanual.pluva.io/assets/ion/kr/pluva-ion-usermanual-kr/ic_more.svg) 아이콘을 누릅니다

<figure><img src="../../.gitbook/assets/image (34).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
\[수정]을 선택합니다.

<figure><img src="../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
필드 수정 모달이 확인 되면, 원하는 정보의 수정을 마친 후 \[수정 완료]를 눌러 수정을 완료합니다.

<figure><img src="../../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

#### **필드 수정 화면 설명** <a href="#desc" id="desc"></a>

* 설정된 필드 이름입니다.

<img src="../../.gitbook/assets/image (45).png" alt="" data-size="line"> **농장**

* 설정된 농장 이름입니다.
* 클릭하면 사전에 저장된 다른 농장으로 변경이 가능합니다.

<img src="../../.gitbook/assets/image (46).png" alt="" data-size="line"> **농장 추가**

<img src="../../.gitbook/assets/image (47).png" alt="" data-size="line"> **농장 소유자**

* 클릭하면 사전에 저장된 다른 농장 소유자로 변경이 가능합니다.

<img src="../../.gitbook/assets/image (48).png" alt="" data-size="line"> **농장 소유자 추가**

<div align="left"><figure><img src="../../.gitbook/assets/image (55).png" alt="" width="375"><figcaption><p>농장 소유자와메모를 작성한 뒤 [추가]를 눌러 농장을 추가할 수 있습니다.</p></figcaption></figure></div>

<img src="../../.gitbook/assets/image (49).png" alt="" data-size="line"> **작물 이름**

* 설정된 작물 이름입니다.
