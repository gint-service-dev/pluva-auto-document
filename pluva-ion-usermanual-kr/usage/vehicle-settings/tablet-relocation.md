# 태블릿 이전

추가 키트 설치와 차량 보정을 모두 완료한 후에는 태블릿만 사용할 차량으로 옮겨 연결합니다. GNSS 수신기가 인식되면 해당 차량의 설정이 적용됩니다.

***

### 이전 방법

{% stepper %}
{% step %}
태블릿을 사용할 차량으로 옮겨 연결합니다.
{% endstep %}

{% step %}
차량을 인식할 때 까지 잠시 대기합니다.

<figure><img src="../../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
차량 연결 완료 안내가 표시되면 \[확인]을 누릅니다.

<figure><img src="../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
트랙터에서 작업기 장착 해제 안내가 나타나면 \[작업기 장착]을 누릅니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (117).png" alt="" width="375"><figcaption></figcaption></figure></div>

{% hint style="info" %}
이앙기는 안내 창에서 \[확인]을 누르세요. 작업기 선택 단계는 진행하지 않습니다.

![](<../../.gitbook/assets/image (119).png>)
{% endhint %}
{% endstep %}

{% step %}
트랙터는 실제 차량에 장착한 작업기의 \[작업기 선택]을 누릅니다.

<figure><img src="../../.gitbook/assets/image (118).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
이앙기는 안내 창을 확인하고, 트랙터는 작업기를 선택하면 태블릿 이전이 완료됩니다.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
**자율주행 전 차량 전환 및 보정 상태를 확인해 주세요.**

* 차량 확인: ![](<../../.gitbook/assets/image (113).png>) \[차량] 버튼을 눌러 확인하세요.
* 보정 상태: ![](<../../.gitbook/assets/image (114).png>) \[차량] 버튼을 누른 뒤 \[오토스티어 보정]을 눌러 확인하세요.
{% endhint %}
