# 차량 변경

하나의 태블릿을 여러 차량에서 사용하는 경우, 이미 등록된 차량을 선택하여 현재 연결된 차량으로 변경할수 있습니다.

***

{% stepper %}
{% step %}
변경할 차량의 GNSS 수신기를 태블릿에 연결합니다.
{% endstep %}

{% step %}
확인되는 팝업에서 \[확인]를 누릅니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (108).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
\[차량 변경]에서 차량을 선택합니다.

<figure><img src="../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
**차량 변경 시 유의 사항**

* 등록된 차량은 새로 추가하지 말고 \[차량 변경]에서 선택해 주세요.
* 같은 차량을 중복 등록했다면 중복 차량을 삭제해 주세요.
{% endhint %}
{% endstep %}
{% endstepper %}
